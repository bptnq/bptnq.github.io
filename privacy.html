Delta - Privacy Policy

Last updated: November 17, 2026

Delta is a personal assistant application used only by its owner (bpt.nq). It is not offered to the public.

Data accessed. With the owner's explicit Google consent, Delta reads and drafts emails (Gmail), reads and updates calendar events (Google Calendar), and uploads files to Google Drive, only on the owner's own accounts.

Use. This data is used only to provide assistant features to the owner (summaries, reminders, drafts, calendar bookings). It is never sold, shared with third parties, or used for advertising.

Storage. Access tokens and data stay on the owner's own computer. Nothing is stored on external servers operated by Delta.

Google API Services. Delta's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation. Access can be revoked at any time at myaccount.google.com/permissions.

Contact: bptnq.business@gmail.com
